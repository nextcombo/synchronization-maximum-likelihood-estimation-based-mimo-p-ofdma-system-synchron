Conclusion
In this project, we developed an MLFD suitable for DFT and DHT P-OFDM. Two LLF and CC of two P-OFDM systems have been exported and drawn. Gradient method can track frequency error. In the case of P-OFDM, the distribution of input data to OFDM block approximates to Gaussian distribution, while for existing conventional OFDM scheme, QAM input data symbols are assumed. It has been shown that the existing MLFD correctly performs in DHT P-OFDM. Compared with DHT coding, DFT coding has poorer robustness in frequency capture and tracking.
Given the main advantage of P-OFDM is reducing the impact of spectrum nulls on system performance. It can be observed that in higher SNR >40 db, the performance of P-OFDM is similar to OFDM in BER analysis. However, the peak-to-average power ratio of P-OFDM system is better than that of OFDM system [14]. A synchronization algorithm for frequency and timing recovery in the uplink of P-OFDMA system has been proposed. They utilize the knowledge of pilot symbols and require limited computational load. Compared with other existing methods, they have fast capture and can be used in different users subcarrier interweaving applications. Their performance has been studied through theoretical analysis and computer simulation. It has been found that receivers with these algorithms actually have the same performance as a fully synchronized system.
